# 헷갈리지 않게 webapps 폴더 구조 (기존 실습 / MVC 실습 구분)

## 기존 실습 (원래 그대로 유지)
- 소스: `src/com/my/order`, `src/com/web`
- 화면: `hello/*.jsp`, `hello/jsp/*.jsp`
- 클래스: `hello/WEB-INF/classes/AdvancedOOP/...`
- DB: `hello/WEB-INF/data/customer.db`

## MVC 실습 (새로 분리)
- 소스: `mvc-src/com/my/order` (Model), `mvc-src/com/web/mvc` (Controller)
- 화면: `hello/mvc/jsp/BrowseCustomers1.jsp`, `hello/mvc/jsp/CustomerView.jsp` (View)
- 클래스: `hello/WEB-INF/classes/com/my/order`, `hello/WEB-INF/classes/com/web/mvc`
- DB: `hello/WEB-INF/data/mvc/customer.db`
